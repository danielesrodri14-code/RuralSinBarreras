# RuralSinBarreras

Prototipo académico de repositorio de recursos educativos digitales para un contexto educativo rural.

## Publicación en GitHub Pages

1. Crear un repositorio público llamado `RuralSinBarreras`.
2. Subir el archivo `index.html` en la raíz del repositorio (puede subirse también este README).
3. Ir a Settings > Pages > Build and deployment.
4. Seleccionar Source: Deploy from a branch; Branch: main; Folder: /(root); Save.
5. Cuando GitHub muestre `Visit site`, abrir el enlace público.

## Alcance

Esta versión es un **prototipo académico**. Los recursos de ejemplo son demostrativos. Los registros se guardan en el `localStorage` del navegador del visitante: no hay autenticación real, base de datos, almacenamiento compartido ni subida real de archivos. No ingresar datos personales reales de estudiantes.
