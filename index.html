¿Qué puedes hacer?

Este sitio es un prototipo académico. Los recursos de ejemplo son ficticios, los perfiles se simulan y no existe almacenamiento en servidor ni autenticación real.
Consultar y descargar

Biblioteca de recursos

Consulta materiales aprobados. Las fichas de ejemplo pueden descargarse como texto; los archivos cargados durante la demostración no se envían a ningún servidor.

Docentes

Publicar un recurso

Registra un recurso con información descriptiva. Quedará pendiente de evaluación antes de mostrarse en la biblioteca.

En el prototipo, esta sección se habilita seleccionando el rol Docente o Administrador. Los datos se almacenan solo en el navegador mediante localStorage. No subas datos reales de estudiantes.
Selecciona el perfil Docente o Administrador para probar el formulario.
Para mantener ligera la demostración, se guarda el nombre del archivo, pero no su contenido. La plataforma definitiva necesitaría almacenamiento seguro y controles de licencia.
Control de calidad

Evaluación de recursos

La evaluación considera pertinencia, claridad, calidad pedagógica, accesibilidad y respeto por los derechos de autor.

Para aprobar o solicitar ajustes, selecciona el perfil Evaluador o Administrador. Las decisiones son simuladas en este navegador.
Selecciona el perfil Evaluador o Administrador para revisar recursos.

Rúbrica de revisión (1 a 5)

  • Pertinencia: relación con currículo, grado y contexto rural.
  • Claridad: instrucciones comprensibles y organización.
  • Calidad pedagógica: propósito y actividades coherentes.
  • Accesibilidad: lenguaje claro y formatos utilizables.
  • Licencia y autoría: procedencia e indicación de permisos.
Acompañamiento educativo

Actividades y orientaciones

Simulación de entrega

No se adjuntan ni guardan trabajos. La función demuestra el recorrido previsto.

En una implementación real, la entrega de trabajos y el seguimiento académico requerirían autenticación, autorización institucional y protección de datos de menores. No forman parte del núcleo del repositorio.
Guía de uso

¿Cómo funciona RuralSinBarreras?

Recorrido propuesto para docentes, estudiantes, evaluadores, administradores y acudientes.

Flujos principales

1. Publicación
Docente completa metadatos y envía a revisión.
2. Control de calidad
Evaluador aprueba o devuelve el material con observaciones.
3. Consulta
Usuario busca, revisa la ficha y descarga el recurso.
4. Mejora
La evaluación permite actualizar la calidad de los materiales.

Preguntas frecuentes

¿Se puede usar sin internet?

La interfaz de este archivo puede abrirse localmente. Los recursos descargados previamente pueden consultarse sin internet si su formato lo permite. La futura plataforma requerirá conectividad para sincronizar materiales.

¿Dónde quedan los recursos que publico?

En esta demostración solo se guardan los metadatos localmente en el navegador. No se almacena el archivo adjunto ni se comparte con otros usuarios.

¿Puedo subir información de estudiantes?

No. Este prototipo no está preparado para información personal de niños, niñas y adolescentes.

¿Cómo reinicio la demostración?

Puedes borrar los registros locales creados durante la prueba usando el botón inferior.

Accesibilidad y conectividad

Se propone priorizar formatos livianos, navegación con teclado, títulos claros, descripciones textuales para imágenes y descarga previa de recursos. Estas medidas deben comprobarse con usuarios de las sedes rurales.
